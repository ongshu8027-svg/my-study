 파이썬에서 가변(Mutable) 객체와 불변(Immutable) 객체의 차이
 판다스에서 view와 copy의 차이

파이썬: 가변(Mutable) vs 불변(Immutable) 객체

 가변 (Mutable) 객체

개념: 생성 후 내부 값을 변경할 수 있음 (in-place)

특징: 값을 바꾸어도 메모리 주소(id)가 유지됨

대표 종류: list, dict, set

예시: a = [1, 2]; a.append(3) -> 주소 동일

 불변 (Immutable) 객체

개념: 생성 후 절대 값을 바꿀 수 없음

특징: 값을 바꾸려고 하면 새로운 메모리 객체를 생성함

대표 종류: int, float, str, tuple

예시: x = 10; x = 20 -> 새로운 객체 생성 및 주소 변경

판다스(Pandas): View vs Copy

 View (뷰)

개념: 원본 데이터의 메모리 주소(참조)를 그대로 공유

특징: 뷰를 수정하면 원본 데이터도 함께 변경됨

주의점: 출처가 불분명할 때 수정하면 'SettingWithCopyWarning' 경고 발생

 Copy (복사본)

개념: 원본과 완전히 독립된 새로운 메모리 공간에 복사

특징: 복사본을 수정해도 원본 데이터는 전혀 영향 없음

권장: 안전하게 데이터를 가공하고 싶다면 명시적으로 '.copy()' 사용

[한 줄 요약]

파이썬 객체: 고쳐 써도 되면 가변(Mutable), 새로 만들어야 하면 불변(Immutable)

판다스: 원본 보호를 위해 안전하게 .copy()를 써야함
