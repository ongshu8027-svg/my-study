[AI → ML → DL 관계]

1. 인공지능(AI)

* 가장 큰 상위 개념
* 인간의 학습·추론·지각 등을 컴퓨터가 구현

2. 머신러닝(ML)

* AI의 하위 분야
* 데이터를 통해 컴퓨터가 스스로 규칙을 학습
* 예측·분류 등에 사용

3. 딥러닝(DL)

* ML의 하위 분야
* 인공신경망을 이용해 학습
* 대량의 데이터에서 강점을 보임

→ 관계: AI ⊃ ML ⊃ DL

[지도학습 vs 비지도학습]

1. 지도학습

* 정답(Label)이 있는 데이터를 사용
* 입력과 정답의 관계를 학습
* 예: 스팸 메일 분류, 집값 예측, 고양이 사진 분류

→ 핵심: 정답 O → 예측·분류

2. 비지도학습

* 정답(Label)이 없는 데이터를 사용
* 데이터의 패턴·구조·공통점을 스스로 찾음
* 예: 고객 군집화, 데이터 그룹화, 이상 감지

→ 핵심: 정답 X → 패턴·구조 발견
