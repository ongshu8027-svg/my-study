1. HTML, CSS, JavaScript 개념과 역할
HTML: 웹 페이지의 뼈대와 구조를 만드는 언어다. 글, 이미지, 버튼 같은 요소들을 화면에 배치할 수 있다

CSS: 웹 페이지를 디자인하는 언어다. 색상, 크기, 배치, 폰트등등 스타일을 지정할 수 있다.

JavaScript: 웹 페이지에 동적인 기능과 동작을 부여하는 언어다. 클릭 반응·애니메이션·데이터 처리 등을 담당합니다.

2. Flex와 Grid 차이점
Flexbox: 1차원(가로 또는 세로 한 방향) 정렬 기술이다. 메뉴바나 아이콘 모음처럼 한 줄로 요소를 나열할 때 적합하다.

Grid: 2차원(가로와 세로 양방향) 정렬 기술이다. 바둑판 형태의 갤러리나 웹사이트 전체 레이아웃을 잡을 때 적합하다.

핵심 차이: Flex는 한 줄 방향 정렬에 특화되어 있고, Grid는 격자(바둑판) 모양의 복잡한 레이아웃이다.
